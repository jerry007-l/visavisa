## 🐛 常见问题和解决方案

### 问题A: "Dialogue is not defined"
**原因:** dialogue.js 加载失败  
**解决:** 
1. 检查控制台是否有其他JS错误
2. 检查 Network 标签，看 dialogue.js 是否成功加载
3. 确认文件存在于 `public/js/dialogue.js`

### 问题B: 按钮点击没有任何反应
**原因:** onclick 绑定失败或 DOM 元素不存在  
**解决:**
1. 在控制台输入: `document.querySelector('#materialReview .btn-primary')`
2. 如果返回 null，说明HTML结构有问题
3. 刷新页面重试

### 问题C: TypeError 或其他错误
**原因:** 某个对象或变量未定义  
**解决:** 将错误信息告诉我，我会修复具体问题
