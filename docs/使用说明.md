## 📖 游戏玩法指南

### 第一步：选择角色
- 👔 **签证官** - 判断申请人是否诚实
- 🧳 **申请人** - 努力获得签证通过

### 第二步：购买道具（可选）
- 使用初始200金币购买辅助道具
- 60秒限时，超时不能买
- 金币可以跨局保存

### 第三步：选择饮品
- 🧋 奶茶 - 手抖但甜蜜
- ☕ 咖啡 - 语速加快
- 🍵 绿茶 - 镇定但话多
- 🥤 果汁 - 稳定状态
- 🍶 清酒 - 微醺易露馅
- 💧 白水 - 正常无影响

### 第四步：材料审核
- 随机抽到2份材料
- 检查是否有伪造痕迹
- 签证官可以点击查看详情

### 第五步：回答问题
- 8轮搞笑问题
- 每题30秒倒计时
- 选对加分，选错扣分
- 30%概率触发随机事件

### 第六步：最终决策
- 签证官：决定通过或拒签
- 申请人：等待结果或主动结束

### 第七步：查看结算
- 金币增减
- 成就解锁
- 统计数据

## 💡 新手技巧

### 作为签证官：
1. 先用"黑名单扫描"查高危身份
2. 用"AI情绪分析"检测说谎
3. 注意材料中的破绽

### 作为申请人：
1. 购买"深度P图"让材料变真
2. 选"记忆魔法"跳过难题
3. 饮品推荐选果汁（最稳定）
4. 答题要自信，哪怕瞎说

### 金币管理：
- 初始200VC足够买1-2个道具
- 胜利+80，失败-50
- 建议先攒钱再买大件
- 别把所有钱都花光！

## ❓ 常见问题

**Q: 游戏没有声音怎么办？**
A: 检查浏览器是否允许音频，点击页面开启音效。

**Q: 选择题没反应？**
A: 刷新页面重试，清除缓存。

**Q: 数据丢了怎么办？**
A: 数据在本地浏览器，清理缓存会丢失。不要清除localStorage。

**Q: 可以在手机上玩吗？**
A: 可以！同一Wi-Fi下访问 http://电脑IP:3000

**Q: PWA怎么安装？**
A: Chrome/Edge: 菜单 → "添加到主屏幕"

**Q: 需要联网吗？**
A: 不需要！纯单机版本。

**Q: 支持存档吗？**
A: 自动保存，刷新不会丢失数据。

## 🔧 高级设置

### 重置数据
如果出现问题，可以重置所有数据：
```javascript
// 在浏览器控制台输入
localStorage.removeItem('visaGame')
location.reload()
```

### 查看数据
```javascript
// 在浏览器控制台输入
console.log(localStorage.getItem('visaGame'))
```

### 修改金币
```javascript
// 加1000金币
const d = JSON.parse(localStorage.getItem('visaGame'))
d.coins += 1000
localStorage.setItem('visaGame', JSON.stringify(d))
location.reload()
```
