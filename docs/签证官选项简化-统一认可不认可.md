## 💡 设计理念

### 1. **专业性提升** 🎓
```
❌ 旧表述: "相信/不相信" - 像日常聊天
✅ 新表述: "认可/不认可" - 正式决策
```

**类比**:
- 法院判决: "有罪/无罪"（不是"相信你犯罪了"）
- 医生诊断: "确诊/排除"（不是"相信你病了"）

---

### 2. **客观性增强** ⚖️
```
❌ 旧表述: "在撒谎" - 直接定性
✅ 新表述: "表现可疑" - 基于观察
```

**心理学原理**:
- 评价行为，而非人品
- 基于可见证据，而非直觉判断

---

### 3. **用户体验优化** 🎮
```
❌ 旧提示: "判断是否诚实" - 抽象
✅ 新提示: "点击'认可'或'不认可'" - 具体
```

**认知负荷**:
- 减少理解成本
- 降低学习门槛
- 更快上手
