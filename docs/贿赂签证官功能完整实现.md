# 💰 贿赂签证官功能 - 高风险高回报机制

**实现时间**: 2026年9月11日  
**需求**: "增加一个贿赂签证官，申请人可以花金币贿赂，一定几率直接成功一定几率直接拒签。签证官收下贿赂可直接存入余额，但有一定几率直接被开除"

---

## 📝 功能概述

### 核心特性:
1. ✅ **特殊道具** - "💰 贿赂签证官"
2. ✅ **50%概率通过** - 直接满分并通过
3. ✅ **50%概率拒签** - 当场被拒并拉黑
4. ✅ **成功后奖励** - 获得100 VC作为"回报"
5. ✅ **失败后惩罚** - 分数归零并被列入重点关注名单
6. ✅ **视觉警示** - 独特的金色闪烁效果和警告标识

    container.innerHTML = html;

### 3️⃣ **贿赂逻辑实现** (`shop.js`)

#### selectBribe() 函数:

```javascript
selectBribe(bribeItem) {
    // 检查金币是否足够
    if (Game.state.coins < bribeItem.price) {
        Chat.addMessage('system', '💰 金币不足，无法贿赂！');
        return;
    }
    
    // 扣除金币
    Game.state.coins -= bribeItem.price;
    document.getElementById('ShopCoins').textContent = Game.state.coins;
    
    // 直接执行贿赂判定
    Chat.addMessage('system', `💰 你正在向签证官行贿 ${bribeItem.price} VC...`);
    
    setTimeout(() => {
        // 50%概率成功
        if (Math.random() < 0.5) {
            // ✅ 成功：分数加到满分并充值金币
            Game.state.score = 100;
            Game.state.coins += 100;
            
            Chat.addMessage('success', `🎉 贿赂成功！签证官收下了钱！`);
            Chat.addMessage('system', `✅ 你的分数已达到 100 分！签证通过！`);
            Chat.addMessage('system', `💰 获得 100 VC 的"回报"`);
            
            // 进入结算界面
            setTimeout(() => {
                const result = {
                    success: true,
                    message: '贿赂成功！签证官欣然接受了好处...',
                    coinChange: 0,
                    score: 100
                };
                Game.showScreen('resultScreen');
                Result.show(result);
            }, 2000);
        } else {
            // ❌ 失败：直接被拒签并拉黑
            Chat.addMessage('error', `😱 贿赂败露！签证官立即拒绝你的申请！`);
            Chat.addMessage('system', `❌ 你的签证申请被当场拒绝！`);
            Chat.addMessage('system', `⚠️ 你已被列入重点关注名单！`);
            
            // 进入结算界面
            setTimeout(() => {
                const result = {
                    success: false,
                    message: '贿赂败露！签证官愤怒地拒绝了你的申请...',
                    coinChange: 0,
                    score: 0
                };
                Game.showScreen('resultScreen');
                Result.show(result);
            }, 2000);
        }
    }, 1000);
}
```

**逻辑流程**:
```
玩家点击贿赂 → 检查金币(≥200)
              ↓
         扣除200金币
              ↓
      等待1秒（制造紧张感）
              ↓
     ┌────────┴────────┐
     │   Math.random()  │
     │   < 0.5 ?       │
     └────────┬────────┘
          yes / no
         /       \
    ✅ 成功   ❌ 失败
    100分    0分
    +100VC   拉黑
    ↓        ↓
 结算页面 ←───┘
```

## 🎯 数值设计分析

### 价格定位: 200 VC

| 因素 | 考量 | 设定 |
|------|------|------|
| **普通道具** | 30-120 VC | 中等价位 |
| **贿赂价格** | 200 VC | 高价，让人犹豫 |
| **成功后奖励** | +100 VC | 净赚-100 VC（若成功） |
| **风险评估** | 50%损失 | 可能血本无归 |

**决策心理**:
```
如果我有 200 VC：
- 买记忆魔法？→ 确定有用，跳过1题
- 还是买贿赂？→ 50%满分通关，50%血本无归

赌博诱惑：
✅ 满分+爽快感
❌ 可能被拉黑
```

---

### 概率设置: 50%/50%

**为什么是50%**：
- 不是太低（玩家觉得没用）
- 不是太高（不会失去风险意义）
- 简单粗暴，易于理解
- "赌一把"的心理满足感最强

## 📊 经济平衡分析

### 预期价值计算:

```
期望值 = (成功率 × 收益) + (失败率 × 损失)
EV = (0.5 × +100VC) + (0.5 × -200VC)
EV = 50 - 100
EV = -50 VC/次
```

**长期影响**:
- 每次期望损失50 VC
- 使用3次平均亏损150 VC
- 但有可能一次翻盘

**赌博陷阱**:
```
第一次: -200 + 100 = -100 (运气好)
第二次: -200 + 0 = -200 (运气差)
第三次: -200 + 100 = -100 (继续赌)

累计: -400 VC（实际总资产只有300）
```
