## 🎭 题目设计原则

### 1. **荒诞幽默**
- 问题本身就很搞笑
- 答案选项也充满脑洞
- 提示语也要有趣

**示例**:
```javascript
q: "房产证上的面积怎么是负数？你家有反物质？"
hint: "归咎于技术"
```

---

### 2. **迷之自信**
- 故意设置夸张的选项
- 鼓励玩家展现过度自信

**示例**:
```javascript
q: "你觉得美国总统认识你吗？"
a: ["认识的", "不认识", ...]
hint: "迷之自信"
answer: 0  // 必须是自信的答案
```

---

### 3. **科幻穿越**
- 引入未来科技、时间旅行元素
- 打破现实逻辑

**示例**:
```javascript
q: "说实话，你是不是一个AI机器人？"
q: "护照印章里有一个火星印章？你是去过太空吗？"
```

---

### 4. **政治正确**
- 在敏感话题上搞笑
- 引导玩家选"官方"答案

**示例**:
```javascript
q: "美国总统和马云谁更帅？选错了拒签"
answer: 0  // 必须选总统
hint: "政治正确"
```

---

### 5. **食物拟人**
- 让非生物有生命
- 给日常物品赋予情感

**示例**:
```javascript
q: "如果你是一只汉堡，你会选生菜还是番茄？"
q: "自由女神像要是罢工了你会怎么办？"
```

## 💡 开发者备注

### 设计哲学:
```
真正的幽默不在于问题有多夸张，
而在于选项有多合理。
用最严肃的语气问最荒诞的问题，
让玩家在"这也能行？"中收获快乐。
```

---

### 平衡要点:
1. ✅ **搞笑但不低俗** - 保持格调
2. ✅ **离谱但有逻辑** - 不能纯瞎编
3. ✅ **幽默但有教育意义** - 玩中学
4. ✅ **荒唐但能引发思考** - 深度+
