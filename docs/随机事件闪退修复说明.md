## 🐛 问题1: 随机事件后闪退

### 原始行为：
```javascript
// randomEventHandle.js 第55行
setTimeout(() => {
    Game.showScreen(Game.state.screen === 'randomEvent' ? 'dialogue' : 'mainMenu');
}, 2000);
```

**问题分析**:
- `Game.state.screen` 仍然是 `'randomEvent'`（因为还没切换屏幕）
- 条件判断 `'randomEvent' === 'randomEvent'` → true
- 应该跳转到 `'dialogue'`，但逻辑有问题

**实际表现**: 
- 选择事件选项后，2秒可能直接跳回主菜单
- 或者在某些情况下跳转到错误界面

---

### ✅ 修复方案：

```javascript
// 显示选择结果并返回游戏
setTimeout(() => {
    console.log('🎮 随机事件结束，返回当前环节');
    // 始终返回对话环节（因为随机事件发生在对话期间）
    if (Game.state.screen === 'dialogue') {
        Game.showScreen('dialogue');
    } else {
        // 如果不在对话环节，回到主菜单
        console.warn('⚠️ 当前不在对话环节，返回主菜单');
        Game.showScreen('mainMenu');
    }
}, 2000);
```

**改进**:
1. ✅ 添加了详细的控制台日志
2. ✅ 在事件结束后检查当前屏幕状态
3. ✅ 优先返回 dialogue 页面（因为随机事件通常在对话中触发）
4. ✅ 只有确实在非对话环节才返回主菜单

## 🎭 问题2: 签证官随机事件不符合逻辑

### 原始行为：
所有角色共用同一组选项（applicantChoices），导致签证官看到的是申请人的行动。

**例子**:

| 事件 | 签证官描述 | 签证官选项（错误） |
|------|-----------|------------------|
| 🤧 打喷嚏 | "申请人打了个喷嚏" | "抱歉不好意思" ❌（谁道歉？签证官吗？） |
| 💪 自信爆棚 | "申请人吹牛" | "继续吹" ❌（签证官在吹牛？） |

---

### ✅ 修复方案：为每个角色创建专属选项

#### 修改结构：
```javascript
{
    id: 'phone_ring',
    title: '📱 手机响了',
    applicantDesc: '...',      // 申请人视角描述
    officerDesc: '...',        // 签证官视角描述
    applicantChoices: [...],   // 申请人选项
    officerChoices: [...]      // 签证官选项 ← 新增
}
```

#### 例子对比：

| 事件 | 角色 | 描述 | 选项 |
|------|------|------|------|
| 🤧 打喷嚏 | 申请人 | "我打了个喷嚏" | - 抱歉不好意思<br>- 说有感冒症状 |
| 🤧 打喷嚏 | 签证官 | "申请人打了个喷嚏" | - 递纸巾并表示关心 😊<br>- 趁机检查材料 🔍<br>- 等待继续 |
| 💪 自信爆棚 | 申请人 | "我在吹牛" | - 继续吹<br>- 及时收住<br>- 道歉 |
| 💪 自信爆棚 | 签证官 | "申请人在吹牛" | - 要求提供证明 ⚖️<br>- 幽默回应缓解尴尬<br>- 严肃提醒态度 |
| 📱 手机响了 | 申请人 | "我手机响了" | - 接电话<br>- 挂断<br>- 让签证官接听 |
| 📱 手机响了 | 签证官 | "申请人手机响了" | - 询问是谁的电话 🔍<br>- 查看通话记录<br>- 不追问 |

## 🎯 设计亮点

### 1. **沉浸式签证官体验**
- 你不是在"回答问题"，而是在"做决策"
- 你可以"关心/怀疑/观察"申请人
- 你能主动发现问题（查看通话记录、检查材料）

### 2. **角色差异化设计**
| 申请人核心 | 签证官核心 |
|-----------|----------|
| 证明自己 | 审查判断 |
| 应对突发 | 主动调查 |
| 情绪管理 | 心态控制 |

### 3. **丰富的策略性**
- 签证官可以选择"宽容"或"严格"
- 申请人可以选择"坦诚"或"隐瞒"
- 每个选项都有不同风险和回报

### 4. **用户体验提升**
- 角色代入感极强
- 选项描述生动有趣
- 后果反馈清晰明确
