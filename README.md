# 🎮 面签三分钟 - 单机版

一款搞笑的签证模拟游戏！选择签证官或申请人角色，通过对话、道具和随机事件来体验虚拟签证面签的过程。

## 🚀 快速开始

### 方式一：直接运行（推荐）

```bash
npm install
npm start
```

然后在浏览器访问: `http://localhost:3000`

### 方式二：直接打开HTML

直接双击 `public/index.html` 文件即可在浏览器中运行（纯前端版本）

## 📱 移动端使用

### PWA安装
1. 通过浏览器访问游戏
2. Chrome/Edge: 点击"添加到主屏幕"
3. Safari: 点击分享按钮 -> "添加到主屏幕"

### APK打包
仓库未附带该教程；打包方案为 Capacitor，可查阅其官方文档。

## 📋 游戏流程

1. **角色选择** (30秒) - 选签证官或申请人
2. **道具购买** (60秒) - 用金币购买辅助道具
3. **材料抽奖** - 随机抽取2份材料
4. **材料审核** - 检查材料真伪
5. **对话问答** - 8轮搞笑问题
6. **随机事件** - 突发状况处理
7. **最终决策** - 通过或拒签
8. **结算显示** - 金币增减+成就解锁

## 🛠️ 技术栈

- **前端**: HTML5 + CSS3 + JavaScript (ES6+)
- **存储**: localStorage (数据保存在本地)
- **PWA**: Service Worker + Manifest
- **打包**: Capacitor (安卓APK)

## 🎮 游戏模式

### 签证官模式
- 目标：正确判断申请人是否应该获得签证
- 高危身份：逃犯、非法移民预定、诈骗惯犯等
- 工具：显微镜审查、AI情绪分析、黑名单扫描等

### 申请人模式
- 目标：欺骗签证官获得签证通过
- 隐藏身份：所有申请人都"不可过签"
- 工具：深度P图、假接线员、记忆魔法等
